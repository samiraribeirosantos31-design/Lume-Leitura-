Lume Leitura

Escolha como instalar no seu celular. É grátis.

Android (APK)

Baixar o app

Abra o arquivo baixado e permita a instalação de fontes desconhecidas quando o celular pedir.

iPhone (Safari)

  1. Abra esta página no Safari.
  2. Toque no botão de compartilhar (quadrado com seta).
  3. Escolha Adicionar à Tela de Início.
  4. Toque em Adicionar.

Android sem baixar (Chrome)

  1. Abra o app no Chrome: abrir Lume Leitura.
  2. Menu ⋮ → Instalar app.
